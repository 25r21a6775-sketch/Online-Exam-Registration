ONLINE EXAM REGISTRATION SYSTEM — COLLEGE PROJECT PROTOTYPE

HOW TO RUN
1. Download and extract online_exam_registration.zip.
2. Open the extracted folder.
3. Double-click index.html. It should open in Chrome, Edge, Firefox, or another modern browser.
4. Use the navigation buttons to explore the prototype.

FEATURES
- Student login (demo only; accepts any non-empty ID and password)
- Student details form
- Subject selection
- Exam fee calculation (sample fee: ₹500 per subject)
- Simulated payment (does not charge money)
- Confirmation receipt (copy or print)
- Admin dashboard with registration filters and mark-as-paid action
- Saves demo registration records in browser local storage

IMPORTANT
This is a front-end college project prototype. It does not connect to a real server, college database, authentication service, or payment gateway. Do not enter real passwords or payment information.
